# Week 7 - Full Stack Blog Application

## Overview
This project is a full stack blog application with frontend and backend integration. 
It includes authentication, blog management, APIs, and database connectivity.

## Features
- User authentication and authorization
- Blog creation and management
- Frontend and backend integration
- Database connection using MongoDB
- REST API implementation
- Responsive UI

## Topics Covered
- MERN Stack development
- API integration
- MongoDB Atlas connection
- Express.js routing
- React frontend deployment
- Backend deployment
